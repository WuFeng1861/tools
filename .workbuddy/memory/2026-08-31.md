## clash-controller 新增「实际生效链路自动检测」

用户需求：自动判断真正在用的节点——全局模式只关注 GLOBAL；规则模式关注规则主用的组（如 一元机场.VIP），在该组选了 自动选择/故障转移 时链路继续展开；并要通用（不只适配当前订阅）。另问直连模式逻辑。

### 实现（改的是工具本身：example/clash-controller）

* `app.js`：`/api/clash` 网关新增 `rules` action（GET /rules，用于判断规则主用组）。

* `front.js`：

  * `resolveChain(name)`：递归解析组链到叶子节点（组可能嵌套：一元机场.VIP → 自动选择 → 节点），带循环保护。

  * `computeUsage()`：全局→resolveChain("GLOBAL")；直连→"不走代理"；规则→统计 /rules 里各代理组被引用次数，取最多者为主用组（通用逻辑，缓存 60s）。

  * `renderUsage()` / `updateUsage()`：状态卡里新增「实际使用」横幅，显示 `模式 → 组链 → 叶子节点`，规则模式附带「规则主用「X」（N/Total 条）」。

  * 挂载点：connect / refreshData / silentRefresh / setMode / selectNode 均调用 updateUsage。

* `index.html`：状态卡加 `#usage-bar`。

* `styles.css`：usage-bar 样式。

### 验证（连真实 Clash Verge，改完已还原）

* 全局模式 → `全局模式 → GLOBAL → 香港hytron-手机畅享05` ✓

* 规则模式 → `规则模式 → 一元机场.VIP → 香港hytron-手机畅享01　规则主用「一元机场.VIP」（338/522 条）` ✓

* 一元机场.VIP 选 自动选择 → `规则模式 → 一元机场.VIP → 自动选择 → 香港hytron-手机畅享09` ✓

* 直连模式 → `直连模式：所有流量直连，不经任何代理组` ✓

* 测试后已还原：mode=global、GLOBAL=香港hytron-05、一元机场.VIP=香港hytron-01。

* 4 个源文件已同步覆盖 toolbox 副本。工具重开/刷新页面生效。

### 直连（direct）逻辑要点

* 全局/规则/直连三态里，直连 = 全部流量绕过代理、直连目标服务器，不经任何代理组。

* 订阅规则里也有 DIRECT 目标（本订阅 157 条）：规则模式下命中这些规则的流量（如苹果/国内域）即使整体不是直连模式也会走直连。

* 自动检测在直连模式下显示「不走代理」，此时所有组的当前节点都不参与流量。
