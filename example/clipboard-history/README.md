# 剪贴板历史工具

> **tools 小工具平台**的一个后台常驻工具：自动记录你在系统里复制的文字 / 图片 / 文件，
> 提供历史管理页和一个全局快捷键唤起的**便携悬浮面板**，随时回看、再复制。

- 纯 Node.js（只用内置模块 + 系统 PowerShell），**零 npm 依赖**，开箱即用。
- manifest 里 `autoStart: true`：平台启动即自动在后台运行，界面关掉也不停。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 记录类型 | 文字、图片（PNG 缩略图）、文件清单 |
| 后台常驻 | 独立进程持续监控，关闭界面/关平台窗口到托盘仍继续记录 |
| 去重 | 连按 Ctrl+C 复制相同内容时合并为一条并置顶，不刷屏 |
| 保存条数 | 总条数（默认 200）与图片张数（默认 50）双上限，超限淘汰最旧，置顶项永不淘汰 |
| 持久化 | 历史与设置存到工具目录 `history.json` / `settings.json`，重启保留 |
| 搜索/筛选 | 按关键词、按类型（全部/文字/图片/文件） |
| 置顶/删除/清空 | 单条置顶、单条删除、一键清空（可保留置顶项） |
| 再复制 | 点击任一条即可重新写回系统剪贴板 |
| 实时刷新 | SSE 推送，历史列表即时更新 |
| 全局快捷键 | 默认 `Ctrl+Shift+V` 唤起悬浮面板，可在设置里修改并持久化 |

## 目录结构

```
example/clipboard-history/
├── manifest.json   # 工具元信息（autoStart: true）
├── app.js          # 工具后端（监控/存储/接口/回贴）
├── index.html      # 完整管理页
├── styles.css      # 界面样式（两个页面共用）
├── front.js        # 完整页逻辑
├── quick.html      # 悬浮面板
├── quick.js        # 悬浮面板逻辑
└── package.json    # 零依赖
```

运行时在工具目录自动生成：`history.json`、`settings.json`、`images/`。

## 在平台里安装

平台会自动扫描用户数据目录 `toolbox/`（Windows：`%APPDATA%\com.tools.platform\toolbox`）。

1. 按 `Win + R` 输入 `%APPDATA%\com.tools.platform\toolbox` 回车。
2. 把本目录 `clipboard-history/` 整个复制进去。
3. 回到平台主页面点「刷新」，即出现「剪贴板历史」图标（manifest 带 `autoStart: true`，
   平台下次启动会自动拉起它后台运行）。

> 由于 `autoStart` 是较新平台能力，请确保你的平台版本支持（宿主 `host.js` 已实现自拉起）。

## 使用说明

- **完整页**：点图标进入。顶部搜索 / 类型筛选，右下…；点击某条 = 写回剪贴板；「设置」内可调
  保存条数、图片张数、轮询间隔、去重开关、来源显示、**全局快捷键**等。
- **悬浮面板**：按全局快捷键号出（默认 `Ctrl+Shift+V`，always-on-top 小窗）。输入过滤，
  点某条 → 复制到剪贴板（**面板不关闭**，方便连续粘贴）；回车或 `Esc` 收起。
- **改快捷键**：完整页 → 设置 → 全局快捷键 → 点输入框按下组合键 → 点「应用」。

## 工作原理

```
平台若机 ────────────── 平台主窗口 / 悬浮小窗口
       │  iframe 加载 http://127.0.0.1:<port>/…
       ▼
工具后端 app.js（Node，宿主拉起）
  ├─ 常驻 PowerShell 子进程（STA）轮询剪贴板序列号
  │    序列号变化 → 读取出 文字/图片(存临时PNG)/文件清单 → stdout 打 JSON
  ├─ Node 解析 → 去重(合并置顶) → 存 history.json + images/
  ├─ 容量双上限淘汰
  ├─ REST /api/*（列表/删除/清空/置顶/回贴/设置）+ SSE /api/events
  └─ 回贴：PowerShell Set-Clipboard / SetImage / SetFileDropList
```

## 安全提醒

- 历史记录为**本地明文存储**（`history.json`、图片在 `images/`），仅存本机，不联网。
- 会记录你复制的所有内容（含敏感信息如密码、验证码、个人资料等）。请在可信设备上使用；
  不需要的记录及时删除或「清空」。
- 复制过的图片会以 PNG 保存，注意放别占据过多磁盘（可调小「图片张数上限」）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 没记录到图片 | 确认剪贴板里是“图片”而非“文件”；部分程序复制图片其实是复制文件，会被记录为文件清单 |
| 面板没反应 | 确认工具在运行（启动器里状态为“运行中”）；检查全局快捷键是否与其他软件冲突 |
| 改快捷键报“注册失败” | 该组合被系统/其它软件占用，换一组 |
| 平台重启历史没了 | 检查工具目录 `history.json` 是否存在、是否被占用 |
