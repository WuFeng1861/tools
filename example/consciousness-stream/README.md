# 即意 · 意识流清单

> **tools 小工具平台**的一个悬浮小面板：把此刻脑子里冒出来的每一个念头随手倒进来，
> 回车即入列。窄栏（约 360×540）毛玻璃外观，既可点图标进入，也可用全局热键随时呼出。

本工具是本地 Electron 版「即意 / consciousness-stream」在平台上的忠实复刻。
前端为纯 HTML/CSS/JS（无框架、无构建），逻辑全部通过平台同源接口与工具后端交互。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 快速记录 | 输入框回车即添加一条，自动保留焦点，可连续输入 |
| 进度 | 显示 `n / 20`；达到 20 条显示「你并不空洞 ✨」并充满进度条 |
| 意识流列表 | ⠿ 拖拽把手，序号 + 内容；悬停出现 复制 / 完成 / 删除 操作簇 |
| 复制 | 复制内容到剪贴板，图标短暂变 ✓（1.5s） |
| 完成 | 移入底部「已完成」区，删除线显示，可折叠 |
| 删除 | 单条删除（列表中 / 已完成后均可） |
| 拖拽排序 | 按住条目上下拖动，虚线幽灵预览，松手即保存新顺序 |
| 全部清单 ☰ | 遮罩层列出所有清单：当前标记、重命名、删除、相对时间、首条预览 |
| 多清单 | 新建清单、切换清单、删除清单（删除走面板内自绘确认框） |
| 主题 | 9 个预设色、自选颜色、保存色板、随机、炫彩（彩虹循环）、流光（呼吸渐变）、明暗切换 |
| 实时同步 | SSE 推送，任何变更即时刷新 |
| 旧数据迁移 | 检查原版数据源与快照、导出快照、导入历史数据 |
| 呼出/收起 | 全局热键开/关；`Esc` 隐藏；`─` 与 `×` 隐藏 |

## 热键

默认 **`alt+x`**：一键开 / 关悬浮面板。想换一组可在平台的「设置 → 快捷键」里修改。

## 安装到平台

1. 把 `example/consciousness-stream/` **整个目录**复制到平台工具目录：
   Windows 为 `%APPDATA%\com.tools.platform\toolbox\`。
2. 回到平台主页面点「刷新」，即出现「即意」图标。
3. manifest 带 `autoStart: true`，平台下次启动会自动在后台常驻拉起（关掉界面也不停）。

## 旧数据迁移

在面板底部点「旧数据迁移」，弹窗内提供三个动作：

- **检查**：列出原版数据源文件是否存在、以及 `legacy/` 下已有的快照清单。
- **导出**：把当前数据导出为一份快照，自动保存到工具目录的 `legacy/` 下，并显示路径与条数。
- **导入**：从快照导入历史数据（清单 / 条目 / 已完成），完成后自动刷新全部界面。

推荐流程：先「导出」生成快照 → 再「导入」。若工具目录已预置 `data.json`，也可直接导入使用。

## 本地独立调试

```bash
cd example/consciousness-stream
node app.js
# 未注入 TOOL_PORT 时默认监听 3900，用浏览器打开 http://127.0.0.1:3900
```

> 说明：平台运行时会注入 `TOOL_PORT` 环境变量，工具监听该端口不受影响。
> 未注入时按默认端口 3900 启动，便于脱离平台单独调试前端。

## 平台能力限制

与原 Electron 版相比，以下能力平台**未向工具开放**，故本工具未实现：

| 原版能力 | 现状 |
|---|---|
| 边缘隐藏（拖到屏幕边缘自动隐藏） | 平台未开放窗口贴边监听，未实现 |
| 独立系统托盘 | 平台未开放托盘 API，未实现 |
| 默认热键 `Alt+=` | 平台不支持该组合，改为 `alt+x`（可在设置中修改） |
| 面板拖拽缩放 | 面板尺寸由 manifest 固定，不可缩放；面板内可拖动标题栏移动窗口 |

## 目录结构

```
example/consciousness-stream/
├── manifest.json   # 工具元信息（由平台侧生成）
├── app.js          # 工具后端（由平台侧生成）
├── package.json    # 零依赖
├── index.html      # 即意界面（面板与完整页共用）
├── styles.css      # 全部样式（主题 CSS 变量）
├── app-ui.js       # 全部前端逻辑
└── README.md
```

运行时在工具目录自动生成：`data.json`，以及迁移用的 `legacy/` 快照目录。
