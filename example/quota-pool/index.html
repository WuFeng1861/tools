加入账户

如何加入账户（按类型看）

WorkBuddy 号：从本机登录态复制（推荐本机号这么加）
  1. 在本机装好 WorkBuddy 客户端并登录一次（微信/手机号均可）。
  2. 用 PowerShell 取 token（明文 JSON，只读你自己的会话）：
    Get-Content "$env:LOCALAPPDATA\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info" -Raw
    只需要其中 auth.accessToken 和 auth.refreshToken。取单个字段：
    ((Get-Content "$env:LOCALAPPDATA\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info" -Raw | ConvertFrom-Json).auth.accessToken)
  3. 找不到文件？旧版本在 %APPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info，或确认客户端确实登录过。
  4. 把两个 token 分别贴到上面表单。accessToken 约 60 天过期，refreshToken 约 90 天；填了 refresh 的话 60 天内点“刷新”自动续，不用重登。
  5. 别人的号：让对方在他自己电脑同样取一次发你（token 等同密码，传完让对方注意保管，泄露去客户端重登即失效）。
Trae 号：token + 已绑定的 deviceId 缺一不可
  1. 该账号先在它自己的 Windows 电脑装 TraeWork 桌面端并登录一次（完成设备绑定，这是官方要求）。
  2. 在那台电脑打开 %APPDATA%\TRAE SOLO CN\ModularData\ckg_server\local_env.json，记下 device_id。
  3. token 获取（二选一）：跑 trae-signin / traework2api 的 login.ps1 按提示登录换 token；或用内存扫描脚本从已登录的 TRAE SOLO CN.exe 提取 JWT（以 eyJ 开头）。
  4. 把 token + deviceId 一起贴到表单。deviceId 错了会 9074（看着像成功其实没到账），且一台设备一天只能签一个号，多号不要共用同一个 ID。
  5. token 短命是正常的：过期后重新走第 3 步贴新 token 即可，deviceId 不变。

自动签到

工具常驻后，每天到点自动给全部启用的账户查状态 + 签到（已签跳过），结果记到运行日志。若到点时电脑没开，下次启动后 30 秒内自动补签。失败自动重试 3 次（间隔 10s/30s），token 过期、9074 这类致命错误不重试，直接标红等你处理。本工具已是后台常驻（autoStart），关掉页面也不会停，托盘右键 → 后台工具可直达。
